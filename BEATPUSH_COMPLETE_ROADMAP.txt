PART 1: THE VISION
================================================================================

MISSION:
Help upcoming Nigerian/African artists, DJs, and producers monetize their 
talent while building a supportive community. No competition with Spotify/
SoundCloud - we focus on BUSINESS and INCOME for emerging talent.

THE ECOSYSTEM FLYWHEEL:
1. DJs upload mixes → Fans discover new artists
2. Artists get exposure → Artists buy beats from Producers
3. Producers make money → Artists release songs
4. DJs play the songs → Fans tip everyone
5. CYCLE REPEATS ✨

UNIQUE VALUE PROPOSITION:
- Affordable Nigerian pricing (₦100-5,000 transactions)
- Multiple income streams for each creator type
- Direct artist-to-fan relationships
- Local payments (Paystack, bank transfer, mobile money)
- Afrocentric genres (Afrobeats, Amapiano, Highlife, Gospel)

users table:
  + user_type (artist/dj/producer/fan)
  + profile_completed (boolean)
  + genres (JSON array)
  + bio (text)
  + social_links (JSON)

tracks table (new):
  - id, user_id, title, genre, file_url, cover_url
  - duration, plays, downloads, is_premium, price
  - created_at, updated_at

beats table (existing - enhance):
  + lease_price, exclusive_price
  + bpm, key, mood, tags
  + preview_url, full_url

mixes table (new):
  - id, dj_id, title, cover_url, file_url
  - duration, plays, downloads
  - tracklist (JSON), featured_artists (JSON)

tips table (new):
  - id, sender_id, receiver_id, amount

  - created_at

  - id, creator_id, fan_id, tier

RISK 2: Payment Fraud
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Mitigation:
  - Paystack handles fraud detection
  - Escrow system (hold funds 24-48 hours before payout)
  - Verify user identity (phone number, BVN)
  - Monitor suspicious transaction patterns
  - User ratings/reviews system

RISK 3: Copyright Issues
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Mitigation:
  - Clear terms of service (users own content)
  - DMCA takedown process
  - Audio fingerprinting (detect copied beats)
  - Dispute resolution system
  - Legal disclaimer in upload flow

RISK 4: Low Engagement
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Mitigation:
  - Gamification (badges, levels, leaderboards)
  - Weekly challenges and contests
  - Featured creator spotlight
  - Email/push notifications for engagement
  - Community building (Discord, WhatsApp groups)

RISK 5: Technical Failures
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Mitigation:
  - Comprehensive error logging (Sentry)
  - Regular backups (database, files)
  - Monitoring and alerts (uptime, performance)
  - Staging environment for testing
  - Gradual rollout of new features
