PROJECT OVERVIEW:
-----------------
BeatPush is an AI-powered platform that helps African music creators (Artists, 
DJs, Producers) distribute music, automate promotion, track analytics, earn 
money through tips/bookings/sales, and manage licensing - all in one place.

UPDATED TECH STACK (Python-Based):
-----------------------------------
Backend:
  □ Python 3.11+
  □ FastAPI (modern async web framework)
  □ SQLAlchemy (ORM)
  □ Alembic (database migrations)
  □ PostgreSQL (main database)
  □ Redis (caching, job queues)
  □ Celery (background tasks)
  □ Pydantic (data validation)

Frontend:
  □ Next.js 14+ with TypeScript (React framework)
  □ Tailwind CSS (styling)
  □ Shadcn UI (component library)
  □ Zustand (state management)

Server:
  □ Ubuntu Server 22.04 LTS (Linux)
  □ Nginx (reverse proxy, load balancer)
  □ Gunicorn (WSGI server)
  □ Supervisor (process management)
  □ Let's Encrypt SSL (HTTPS)
  □ UFW Firewall
  □ Fail2ban (intrusion prevention)

DevOps:
  □ Docker & Docker Compose
  □ GitHub Actions (CI/CD)
  □ Automated backups
  □ System monitoring (Prometheus + Grafana)

  - Hetzner (cheapest, good for Africa)

□ Initial server security hardening:
  - Create non-root user with sudo
  - Disable root SSH login
  - Setup SSH key authentication
  - Disable password authentication
  - Change default SSH port (optional)
  - Setup UFW firewall
